# Take 5 Editor & Librarian

**Made using coding agents for personal use.**

A browser-based patch librarian and editor for the **Sequential Take 5** (OS 2.0).

- **Library:** import `.syx` files or read the whole synth (512 programs). Each patch keeps its full version history, with hearts, auto-tags and random two-word names. Nothing is ever deleted outright.
- **Editor:** every mapped parameter, live in both directions. Turn a knob on the synth and the screen follows; drag on screen and the synth follows.
- **Banks:** plan banks by dragging patches into slots, then push. Each slot is backed up first, and every write is verified by reading it back.
- **Generate:** new patches from sections of your library, children of your favourites, or mutations of any patch.

## Using it

Open in **Chrome or Edge**. Allow MIDI with SysEx when asked, and connect the Take 5 over USB with these Global settings: MIDI Sysex On, Sysex Cable USB, Param Send/Receive NRPN. The first time, choose a library folder (e.g. in iCloud Drive). On any other computer or address, open the same folder and your library is there.
